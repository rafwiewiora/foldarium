# Local cofolding libraries

`library-review.html` is an unscored Foldarium review interface for libraries
generated by Molarium's LocalFold/OpenBind-0 integration. It is separate from
Weekly quizzes, Selector decisions, experimental answers and leaderboards.

Open a `foldarium.cofolding-library.v1` JSON file with **Import library JSON**.
Alternatively, Molarium hosts the same review source on its own origin so the
reviewer can read its local IndexedDB checkpoints directly. Browser storage is
isolated by origin: a run ID on Molarium cannot retrieve a library on Foldarium's
origin. Use the JSON export to move a library between sites or computers.

Review a compound's independently seeded poses in a grid of up to four viewers,
or one at a time. Choose **Prefer**, **Reject**, **Unreviewed**, or **None of these
poses**. More than one pose can be preferred. Notes and exact pose IDs are saved
locally. “None” clears existing preferences for that compound; preferring a pose
clears “none.” Export the full library with decisions, or a shortlist containing
the preferred complexes and their provenance. No correctness label, crystal RMSD,
binding affinity, or fictitious answer is assigned.
Changing a decision or note preserves the current 3D camera and viewer; only
changing compound, page or comparison mode rebuilds the displayed structures.
Each pose labels its prediction model and execution backend. Comparison bundles
can therefore include native and browser predictions together; each record must
retain its own protocol and provenance. Confidence scores remain model-specific.

Each pose retains its own predicted receptor. A least-squares rigid fit using
matching protein Cα atoms places complexes in one frame; the same transform moves
each ligand. Ligands are never fitted to each other. The displayed Cα RMSD is
between predictions, not against an experimental structure. Ligand sticks use
the input component's atom names, bonds, aromatic bond orders and formal charges;
the receptor pocket is the predicted protein within 8 Å of that pose's ligand.
Ligand pLDDT and ipTM are model confidence values and do not establish binding or
pose accuracy.

The catalog contains compact metadata. Full structures are loaded only for the
current compound. Checkpoints and decisions use IndexedDB; a small
BroadcastChannel notification announces new results without transferring
molecular data. Files and coordinates are not sent to an application server.
The standalone page loads Mol* 5.11.0 from jsDelivr; a host may replace those two
asset URLs with its own identical copies. Molarium uses its existing local Mol*
5.11.0 files and retains a source/hash receipt for this small transformation.

The portable format contains a run, compound IDs/SMILES, pose attempts and
decisions. Complete poses contain their protein–ligand PDB, component graph,
model/source provenance and confidence. Interrupted and failed attempts remain
explicit. Typed numerical arrays become JSON arrays. Molarium normally omits the
quadratic PAE arrays while retaining their SHA-256 and shape; its optional
`retainPae` setting preserves those arrays. A shared alignment can be stored once
as `run.alignment`, referenced by each result's provenance. Export/import always
preserves these distinctions. Import assigns a fresh local run ID and cannot
overwrite an active run.

Current bounds: 10,000 compound entries, 20 samples per entry; practical size
depends on browser disk quota, protein length, GPU memory and export size. JSON
import is limited to 500 MB. Split very large libraries. Full export currently
assembles one JSON document in memory; review and execution do not load every
structure at once. Keep explicit backups before clearing browser data.

Validation includes protein-frame alignment and portable-format unit tests,
the existing Foldarium suite, and actual Molarium WebGPU → stored library → grid
review → preference → shortlist → “none” → import round-trip tests. Throughput
measurements belong with the inference host's pinned protocol and hardware;
this viewer does not make speed or scientific accuracy claims of its own.

Deployment status: this source addition does not by itself roll out a route on
the separately operated production Foldarium site. The Molarium-hosted copy can
be released independently, and the portable reviewer can be tested with
`npm start` at `/library-review.html`.
