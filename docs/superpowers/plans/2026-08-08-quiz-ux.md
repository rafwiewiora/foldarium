# Quiz UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce quiz mode to a clear setup, question, and result flow with technical controls hidden by default.

**Architecture:** Keep the existing static `index.html` and classic `app.js`. Add semantic disclosure elements and responsive CSS in the page, then make small state-rendering changes in `app.js`; do not alter quiz data, scoring, persistence, or Mol* behavior.

**Tech Stack:** HTML, CSS, browser JavaScript, Node.js test runner

## Global Constraints

- Keep the existing static HTML and JavaScript architecture.
- Add no dependencies or new runtime modules.
- Preserve quiz scoring, persistence, structure loading, and scientific answer logic.
- Do not modify replay mode.

### Task 1: Lock the minimal UX contract with tests

**Files:**
- Create: `tests/quiz-ux.test.js`
- Test: `tests/quiz-ux.test.js`

**Interfaces:**
- Consumes: `index.html` and `app.js` as source text.
- Produces: regression checks for disclosure controls, primary copy, responsive layout, selected state, and result hierarchy.

- [ ] **Step 1: Write failing source-contract tests**

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { readFile } from 'node:fs/promises';

const readHtml = () => readFile(new URL('../index.html', import.meta.url), 'utf8');
const readApp = () => readFile(new URL('../app.js', import.meta.url), 'utf8');

test('quiz exposes a minimal primary flow and hides technical controls', async () => {
  const html = await readHtml();
  assert.match(html, />Dataset</);
  assert.match(html, />Difficulty</);
  assert.match(html, /Pick the pose that best fits the binding pocket\./);
  assert.match(html, /<details id="view-options"/);
  assert.match(html, /<details id="answer-details"/);
  assert.match(html, />Submit answer</);
});

test('quiz has responsive and accessible state cues', async () => {
  const [html, app] = await Promise.all([readHtml(), readApp()]);
  assert.match(html, /@media \(max-width: 760px\)/);
  assert.match(html, /aria-live="polite"/);
  assert.match(app, /aria-pressed/);
  assert.match(app, /Selected/);
  assert.match(app, /Not quite/);
});
```

- [ ] **Step 2: Run the test and verify it fails**

Run: `node --test tests/quiz-ux.test.js`

Expected: FAIL because the current page has no disclosure sections or revised copy.

- [ ] **Step 3: Commit the failing contract test**

```bash
git add tests/quiz-ux.test.js
git commit -m "test: define minimal quiz UX"
```

### Task 3: Render clear selection and result states

**Files:**
- Modify: `app.js`
- Test: `tests/quiz-ux.test.js`

**Interfaces:**
- Consumes: `#view-options`, `#answer-details`, `#answer-choices`, `#answer-ai`, and existing quiz state.
- Produces: synchronized `aria-pressed` controls, a visible Selected label, concise result copy, and collapsed secondary answer details.

- [ ] **Step 1: Synchronize segmented-control accessibility**

Add a small `selectSegment(selector, dataKey, value)` helper that updates both `.on` and `aria-pressed`, then use it for dataset, difficulty, display mode, and protein mode.

- [ ] **Step 2: Make selection unmistakable**

When rendering a selected choice, add the `.sel` class and set its tag text to `Selected ✓`; clear tags on other choices.

- [ ] **Step 3: Separate the concise result from answer details**

Render `Correct` or `Not quite` in `#verdict`, include the best correct pose when present, render RMSD rows into `#answer-choices`, put the AI comparison in `#answer-ai`, hide the question choices, show `#answer-details` closed, and keep `#next` as the primary action.

- [ ] **Step 4: Reset disclosures on state transitions**

`showIntro()` adds `#wrap.intro` and hides both disclosures. `startQuiz()` removes `.intro` and shows View options. Loading a question hides Answer details and restores question choices. `finish()` hides both disclosures.

- [ ] **Step 5: Run focused and full tests**

Run: `node --test tests/quiz-ux.test.js`

Expected: PASS.

Run: `npm test`

Expected: all tests pass.

- [ ] **Step 6: Commit behavior changes**

```bash
git add app.js tests/quiz-ux.test.js
git commit -m "feat: clarify quiz selection and results"
```
